# Biblioteca Central da UFAC — Página de Links

Página estática, responsiva e sem dependências externas.

## Estrutura

- `index.html` — página principal
- `assets/logo-ufac.png` — logomarca da UFAC
- `assets/logo-biblioteca.png` — logomarca da Biblioteca Central

## Identidade visual

- Azul: `#0c4da2`
- Verde: `#32993d`

## Publicação no GitHub Pages

Para um repositório de usuário chamado `bibliotecacentralufac`, o caminho mais direto é manter
`index.html` na raiz e configurar GitHub Pages para publicar a partir da branch `main`.
